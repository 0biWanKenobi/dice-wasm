# dice-wasm

Browser-compatible Rust/WASM dice expression engine using [Chumsky](https://github.com/zesterer/chumsky).

**Distribution: GitHub Releases only.** Each version tag publishes an installable npm-format
tarball (`.tgz`) as a GitHub Release asset. Nothing is published to the npm registry or GitHub Packages.

## Building

```sh
docker compose run --rm wasm-build
node scripts/prepare-package.mjs
node scripts/check-package.mjs
```

The `dist/` directory contains the ES-module wrapper, TypeScript definitions, and WebAssembly
binary generated by `wasm-pack --target bundler`.

## Using from a TypeScript / Vite project

Install the versioned GitHub Release asset with npm (npm is the package installer here,
not the package host):

```sh
npm install https://github.com/0biWanKenobi/dice-wasm/releases/download/v0.1.0/dice-wasm-v0.1.0.tgz
```

Then import the packaged library by its declared package name:

```ts
import { CompiledFormula } from '@0biwankenobi/dice-wasm';

const compiled = new CompiledFormula('kh(4d8, 2) + 3');
console.log(compiled.rollable()); // true
console.log(compiled.dependencies());
console.log(compiled.roll()); // { value, dice: [{ rolls, kept, total }] }
compiled.free();
```

Use `evaluate()` only for expressions without dice. Fields are referenced with braces, e.g.
`{STR}`; recursive reference resolution and reactivity belong to the consuming application.

## Versioned GitHub Releases

`.github/workflows/release.yml` tests Rust, compiles WASM, checks generated assets, and
archives the build on every push. Pushing a tag matching the crate version also creates a
GitHub Release containing `dice-wasm-vX.Y.Z.tgz`.

To publish version 0.1.0:

```sh
git tag v0.1.0
git push origin v0.1.0
```

For future releases, first bump the version in `Cargo.toml`, refresh `Cargo.lock`,
commit, and push the matching tag. GitHub Actions uses its built-in `GITHUB_TOKEN`
with `contents: write`; no npm account or registry credentials are needed.

The consuming project is
[ts_reactive_character_sheet_test / rust-wasm-engine](https://github.com/0biWanKenobi/ts_reactive_character_sheet_test/tree/rust-wasm-engine).
